DNS-cache [25]
Описание:
Реализовать DNS-сервер, который итеративно опрашивает ответственные за зону серверы 
с ручным формированием запросов и ответов протокола DNS (на 25 баллов) 

Базовая функциональность 
20: если используется ручное формирование запросов и ответов  

Дополнительная функциональность  
3: одновременная работа с несколькими клиентами  
2: поддержка работы как по TCP, так и по UDP
